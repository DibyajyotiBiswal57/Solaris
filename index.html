This is our project

We, The Sun-Sationals ☀️ led by Hrittik Mahata have created a sunlight tracking plant stand. We call it Solaris.

A Demo

What we used

  1. LDR sensor
  2. Servo with 180° rotation
  3. Arduino UNO board
  4. Some cardboard
  5. Some colour papers

How it works

An LDR sensor has been attached above the servo motor which lets it take readings from 0°-180° and check which position gets the most sunlight and turns toward it.
